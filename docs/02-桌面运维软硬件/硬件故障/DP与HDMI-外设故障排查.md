# DP/HDMI 外设故障排查 SOP

## 结论先行

显示器黑屏/无信号按 **物理层(线/口/交叉测试)→ 接口选择(独显 vs 核显)→ 驱动(重装/回滚)→ 系统设置(分辨率/多屏/输入源)** 四层排查。80% 的"插上不亮"是**线材/接口/插错口**问题,只有 20% 是驱动。闪屏优先查 **TDR 事件(Event 4101)** 和刷新率/线材带宽。

## 现象

- 插上 DP/HDMI 无信号,显示器黑屏或"无信号"提示
- 多屏组合时第二屏不亮、分辨率异常、无法扩展
- 间歇性黑屏/闪屏,刷新率掉回 60Hz
- 转接头(DP↔HDMI)不识别、画面异常
- 热插拔后无信号,重启才恢复

## 原因推测(分层定位)

| 层 | 常见原因 | 概率 |
|---|---|---|
| 物理 | 线材损坏/劣质/版本不够、接口氧化/松动、显示器输入源错 | 高 |
| 接口选择 | 插到核显口但驱动/BIOS 禁用核显、笔记本外接没切模式 | 高 |
| 驱动 | 显卡驱动损坏/版本冲突、TDR 超时 | 中 |
| 系统设置 | 多屏模式错误、分辨率超规格、HDCP/输入源 | 中 |
| 供电/兼容 | USB-C 扩展坞供电不足、DP 版本带宽不足 | 低 |

## 分步操作

### 第 1 步:物理层排查(2 分钟,占比最高)

1. **交叉测试**:换一根线(借一根确定好的)→ 换一个接口 → 换一台显示器,三步定位是"线、口、还是屏"
2. 检查接口:DP 口卡扣是否扣紧(DP 线易松脱)、HDMI 口氧化(拔插几次,用无水酒精棉签清)
3. **显示器输入源**:按显示器 OSD 菜单切换输入源(HDMI1/HDMI2/DP),很多"无信号"是输入源没切过来
4. DP 线注意方向(两头都能插但部分线单向标识)与**卡扣到位**

### 第 2 步:确认接口插对(核显 vs 独显)

```powershell
# 查看显卡型号(确认独显/核显)
Get-CimInstance Win32_VideoController | Select-Object Name, Status, DriverVersion
```

- **独显机器**:显示器必须插**独显输出口**(竖着那排),插主板竖排接口(核显口)在独显启用时**默认黑屏**
- 想用核显口:需 BIOS 开启 iGPU 多显示器支持,或装核显驱动
- **笔记本外接**:`Win+P` 切换(仅电脑屏幕/复制/扩展/仅第二屏幕),Fn+ 切换键确认笔记本没禁用外接输出

### 第 3 步:系统层处理

```powershell
# 重新检测显示器(UI:设置 → 系统 → 显示 → 多显示器 → 检测)
# 命令行触发检测
(New-Object -ComObject WScript.Shell).Run("ms-settings:display")

# 确认显示器被识别(WmiMonitorID 有返回 = 识别正常)
Get-CimInstance -Namespace root\wmi -ClassName WmiMonitorID -ErrorAction SilentlyContinue |
  ForEach-Object { ($_.UserFriendlyName -ne 0 | ForEach-Object {[char]$_}) -join '' }
```

- 识别正常但不亮 → 调分辨率/刷新率(显示器 OSD 支持上限内),尝试"复制"模式排除扩展模式问题
- 识别不到 → 回到第 1、2 步

### 第 4 步:闪屏/间歇黑屏专项(驱动 TDR)

```powershell
# 查显卡超时恢复(TDR)事件——闪屏的第一证据
Get-WinEvent -FilterHashtable @{LogName='System'; Id=4101} -MaxEvents 5 |
  Select-Object TimeCreated, @{n='信息';e={$_.Message.Substring(0, [Math]::Min(150, $_.Message.Length))}}
```

- 有 4101 事件 → 显卡驱动问题,进入第 5 步
- 无 4101 但闪屏 → 优先怀疑**线材带宽不够**(如 DP 1.2 线跑 4K@144Hz)或刷新率超规格,降刷新率测试(144→120→60)

### 第 5 步:驱动彻底重装(闪屏/识别异常仍无解时)

```cmd
:: 1. 官网下载对应显卡驱动(NVIDIA/AMD/Intel,认准型号与 Windows 版本)

:: 2. 安全模式用 DDU(Display Driver Uninstaller)彻底卸载旧驱动
::    下载 DDU → 断网 → 安全模式运行 → 清理后重启

:: 3. 正常模式安装新驱动,重启
```

> ⚠️ 卸载前记录当前驱动版本号(便于回滚);驱动不是越新越好,稳定优先——**刚更新驱动后出问题的,先回滚**(设备管理器 → 显卡 → 属性 → 驱动程序 → 回退驱动程序)。

### 第 6 步:转接头与扩展坞专项

| 场景 | 检查要点 |
|---|---|
| DP→HDMI 转接头 | **单向性**:DP 公→HDMI 母(接显示器)才常用;反了不亮。4K 需主动式转接头(带芯片) |
| HDMI→DP | 较少见,多数不支持;用主动式转换器 |
| USB-C 扩展坞 | 供电不足 → 换供电口/带电源的坞;Type-C 直连优先于转接 |
| 线材版本 | DP1.2 线 ≈ 4K60;4K144 需 DP1.4/HDMI2.1 认证线 |

## 验证方法

```powershell
# 确认分辨率/刷新率设置生效
Get-CimInstance Win32_VideoController | Select-Object Name, CurrentHorizontalResolution, CurrentVerticalResolution, CurrentRefreshRate
```

- 目标显示器按预期分辨率/刷新率点亮,多屏拖拽正常
- 闪屏场景:连续使用/游戏 30 分钟无闪屏;TDR 事件无新增
- 重启后冷启动正常(排除热插拔偶发)

## 注意事项 / 踩坑记录

- **插错口是最常见原因**:独显机器插核显口黑屏,先看接口物理位置(独显口在下方独立区域)
- **DP 热插拔偶发无信号**:先 `Win+P` 切"仅电脑屏幕"再切回,或睡眠唤醒;不要马上断定硬件坏
- **显示器"无信号"≠ 显卡没输出**:先切显示器输入源,再查线,最后才查驱动
- 驱动更新后黑屏:安全模式进系统回滚驱动(Shift+重启 → 疑难解答 → 高级选项 → 启动设置 → 4 安全模式)
- **4K 高刷必须好线**:劣质线材表现是"闪屏/掉刷新率/间歇黑",换认证线材立竿见影
- HDMI 线热插拔带电操作一般安全,但雷电/USB-C 扩展坞拔插先安全弹出
- 多屏排列混乱:重置显示器排列(设置 → 显示 → 多显示器 → 标识),别靠记忆拖拽
- 服务器/生产环境接 KVM 的 DP/HDMI:优先确认 KVM 与显卡 EDID 兼容,遇黑屏先切输入源再查线
