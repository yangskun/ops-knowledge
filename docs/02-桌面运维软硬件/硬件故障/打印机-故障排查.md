# 打印机故障排查 SOP

## 结论先行

打印机问题按 **硬件状态 → 打印服务 → 队列 → 连接方式(USB/网络/共享)→ 驱动** 五层排查。80% 的"打印机不打印"是**服务停了、队列卡死、或脱机状态**,别一上来就重装驱动。网络/共享打印记得先分清是"找不到打印机"还是"连上了打不出"。

## 现象

- 打印机显示"脱机"/"暂停",任务堆积在队列
- 点击打印无反应、任务消失、提示错误
- 网络/共享打印机找不到,或连接报错(0x11b、0x709 等)
- 打印乱码、半张纸、颜色异常
- 卡纸、不进纸、报错灯亮

## 原因推测(分层定位)

| 层 | 常见原因 |
|---|---|
| 硬件 | 卡纸、缺纸、硒鼓/墨盒耗尽、USB 线松动、报错灯(故障码) |
| 系统 | **Print Spooler 服务停止**、驱动损坏、端口配置错误、队列堵塞 |
| 网络 | 打印机 IP 变更、防火墙拦截、共享权限/凭据问题 |
| 应用 | 驱动版本不匹配、默认打印机选错、应用内设置 |

## 分步操作

### 第 1 步:硬件状态确认(1 分钟)

1. 电源指示灯、报错灯状态(对照打印机面板故障码)
2. 卡纸:打开盖板沿出纸方向轻轻取出,**不要硬拽**(撕裂后更难取)
3. 纸盒:纸张放正、不超容量、不潮
4. USB 打印机:换根线/换口,看设备管理器是否识别(`通用串行总线控制器` 无感叹号)

### 第 2 步:检查打印服务与队列(最高频原因)

```powershell
# 管理员 PowerShell:查看 Print Spooler 状态(应为 Running)
Get-Service Spooler

# 若停止或故障,重启服务
Restart-Service Spooler

# 清空卡死队列(服务停了才能删文件)
net stop spooler
del /f /s /q C:\Windows\System32\spool\PRINTERS\*.*
net start spooler
```

> 队列里任务"删不掉"时,用上面的删文件方式最彻底。Spooler 依赖 **RPC 服务**(Remote Procedure Call),确认 RPC 也在运行。

### 第 3 步:检查打印机状态与默认打印机

```powershell
# 列出打印机与状态(PrinterStatus 0=正常,3=脱机/暂停等)
Get-Printer | Format-Table Name, PortName, DriverName, PrinterStatus, Shared

# 设为默认打印机
Set-Printer -Name "打印机名称" -Default

# 取消"脱机使用打印机"勾选(UI:打印机 → 脱机使用打印机,取消勾选)
```

### 第 4 步:按连接方式排查

**USB 直连**
```powershell
# 确认端口类型正确(USB 打印机端口应为 USB001 等)
Get-Printer | Select-Object Name, PortName
# UI 核对:打印机属性 → 端口 → 勾选 USB 端口
```

**网络打印机**
```powershell
# 1. 打印机面板确认 IP(网络设置页可打印)
# 2. Ping 通?
Test-Connection 192.168.1.100 -Count 2

# 3. 测试打印端口(RAW 9100 为多数网络打印机默认;HP 常为 9100,部分用 515/631)
Test-NetConnection 192.168.1.100 -Port 9100

# 4. 查看本机端口配置的 IP 是否正确(重点:打印机 DHCP 租约过期会换 IP!)
Get-PrinterPort | Format-Table Name, PrinterHostAddress
```

- Ping 不通 → 打印机网络配置(建议设**静态 IP 或在路由器做 DHCP 保留**)
- Ping 通但端口不通 → 打印机端 RAW 协议未开/防火墙;查打印机"网络配置页"
- 端口通 → 进第 5 步驱动

**共享打印机(最易报错,见错误码表)**
```powershell
# 先确认主机端共享名
# UI:开始 → \\主机IP → 双击打印机
# 或命令行添加(需要凭据权限)
rundll32 printui.dll,PrintUIEntry /in /n "\\192.168.1.10\HP_LaserJet"
```

### 第 5 步:驱动彻底重装(最后手段,别第一步就做)

**卸载(彻底,三步)**

```cmd
:: 1. 删除打印机设备
:: UI:设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 删除设备

:: 2. 删除驱动包(管理员 CMD)
:: UI:控制面板 → 设备和打印机 → 空白处右键 → 打印服务器属性 → 驱动程序 → 删除
:: 或命令行(列出再删,名称要完全一致)
pnputil /enum-drivers | findstr /i "打印机品牌"

:: 3. 重启后安装官网驱动(64 位系统装 64 位驱动,别混装)
```

> ⚠️ 卸载前先备份打印首选项(部分品牌驱动会保留配置);删除驱动包时勾选"删除驱动程序包和驱动程序"。

### 第 6 步:验证

```powershell
# 打印测试页
# UI:打印机属性 → 常规 → 打印测试页
# 命令行(需要打印机名)
(New-Object -ComObject WScript.Network).AddWindowsPrinterConnection("\\主机\共享名")
```

- 测试页正常出纸 = 成功
- 多台电脑分别验证(区分"单机问题"和"共享源问题")

## 常见错误码对照

| 错误码 | 含义 | 处理 |
|---|---|---|
| `0x0000011b` | 共享打印经典报错(2021 年补丁后高发) | 见下方专项修复 |
| `0x00000709` | 找不到打印机/名称冲突 | 检查共享名、凭据;删本地同名打印机 |
| `0x000006d9` | 防火墙阻止(依赖 RPC) | 确认"文件和打印机共享"规则开启 |
| `0x000006ba` | RPC 服务不可用 | 启动 RPC 与 Spooler 服务 |
| `0x00000002` | 打印机脱机/不可用 | 第 3 步脱机处理 |
| `0x80070005` | 访问被拒绝 | 共享权限/凭据(Everyone 或指定用户) |

### 0x11b 专项修复(PrintNightmare 补丁后共享打印报错)

```cmd
:: 客户端与主机端都做(管理员 CMD)
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Print" /v RpcAuthnLevelPrivacyEnabled /t REG_DWORD /d 0 /f
:: 重启 Spooler 后重试
net stop spooler & net start spooler
```

> 说明:该键值恢复旧 RPC 认证行为,可解决 0x11b;若企业安全策略要求隐私级别,改为**双方升级补丁**至 KB5007253 之后版本,或用"凭据管理器"添加主机凭据。

## 注意事项 / 踩坑记录

- **先硬件后软件**:卡纸/缺墨/纸盒问题直接重装驱动是浪费时间
- **IP 是 DHCP 分配的网络打印机**,隔天"找不到"大概率是 IP 变了——优先静态 IP/保留
- **驱动用官网原版**,不要用驱动精灵类工具装打印机驱动(常装错型号/版本)
- 系统位数必须匹配(64 位系统 + 32 位驱动 = 各种诡异问题)
- Windows 更新后打印故障:查最近更新,回滚 KB5005565 系列(0x11b)或更新至修复版
- Spooler 服务被安全软件/加固策略禁用时,打印会静默失败,查服务启动类型
- 卡纸后报"卡纸"但无纸:传感器卡异物,需断电开盖检查
- 大批量打印任务排队时重启 Spooler 会丢任务,先暂停队列再操作
