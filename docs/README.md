## 命名规范

- 文件名:`主题-动词.md`,如 `RAID5-重建流程.md`、`C盘-空间清理.md`
- 每篇开头带元信息(见模板):
  ```markdown
  ---
  日期: 2026-08-20
  标签: [windows, 排错, raid]
  适用环境: 生产/个人设备
  风险等级: 低/中/高
  权限要求: 管理员/root
  ---
  ```
- 标签建议:系统(windows/linux/kylin)、领域(网络/存储/虚拟化/硬件)、动作(排错/配置/脚本/装机)

## 查阅方式

1. 按分类目录进入
2. 每篇开头有"结论先行"段——30 秒内判断是否对症
3. 需要执行型 SOP 时,直接用自然语言告诉我(如"走一遍 RAID 重建流程"),我会加载对应 Skill 执行,不靠翻文档

## 积累规则

- **实战优先**:只有自己踩过/验证过的方案才入库,拒绝搬运未经验证的内容
- **一条一档**:每个问题一篇文档,宁多勿杂
- **与 Skill 联动**:高频、可执行的流程抽成 Hermes Skill(存于 `profiles/bendi/skills/`),知识库保留背景知识和细节,Skill 保留步骤命令
- **定期整理**:遇到新案例随时补充;同一主题多篇后合并

## 与 Hermes 的联动

- 知识库路径 `E:\Documents\Hermes knowledge` 是日常查阅资料
- Hermes Skill 是可执行 SOP,我说"执行 XX 流程"时自动加载
- 新知识建议先入库,用 3 次以上再考虑抽成 Skill
