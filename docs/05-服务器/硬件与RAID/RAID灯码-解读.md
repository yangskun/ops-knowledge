# RAID 故障灯码解读

## 结论先行

灯码是阵列状态的**第一道快速信号**,分三处看:**硬盘状态灯(每盘一盏)、前面板系统状态灯/LCD、阵列卡报警音**。看懂颜色与闪烁规律就能在 30 秒内判断"正常 / 重建 / 预测故障 / 已故障"。⚠️ 灯码只是定位手段,**最终以 OMSA / perccli / iDRAC 软件状态为准**,严禁仅凭灯色直接拔盘。

## 现象

- 机柜巡检发现某盘位指示灯变琥珀/红色,或整机前面板告警灯亮
- 阵列卡持续蜂鸣/规律短鸣
- 服务器管理软件(iDRAC/OMSA)同步报阵列降级

## 原因推测(灯码对应关系)

| 灯码 | 对应 RAID 状态 | 紧急程度 |
|---|---|---|
| 绿色常亮/闪烁 | 在线 / 活动 | 正常 |
| 绿色快速闪烁 | 重建中 / 定位 | 正常,勿打扰 |
| 琥珀色闪烁 | 预测性故障(PFA)或阵列降级 | 中,尽快处理 |
| 琥珀色常亮 | 硬盘故障 | 高 |
| 灯熄灭(盘位有盘) | 离线/未识别/掉电 | 高 |
| 红(部分品牌) | 故障 | 高 |

## 灯码详解(按设备)

### Dell PowerEdge(13G/14G,双灯设计)

**硬盘活动 LED(左)**:绿色闪烁 = 读写活动,正常现象。

**硬盘状态 LED(右)**:

| 状态灯 | 含义 | 动作 |
|---|---|---|
| 绿色常亮 | 硬盘在线,阵列正常 | 无 |
| 绿色闪烁 | 重建中 / 正在识别 | 等待,勿重启 |
| 琥珀色闪烁 | **预测性故障(PFA)** 或阵列 Degraded | 尽快备份并计划换盘 |
| 琥珀色常亮 | 硬盘已故障(Failed) | 立即处理,按换盘 SOP |
| 熄灭 | 未配置 / Offline / 无供电 | 查背板/线缆/阵列配置 |

**前面板系统状态灯 / LCD**:

| 状态 | 含义 |
|---|---|
| 蓝色常亮 | 正常 |
| 琥珀色闪烁/常亮 | 有警告(如阵列降级、温度、电源冗余丢失) |
| 红色 | 严重故障 |
| LCD 面板 | 直接显示错误码(如 `VD Degraded`、盘位号),14G 优先看 LCD |

**报警音(Beep)**:持续长鸣 = 阵列/电源严重故障;规律短鸣组合 = 特定故障(内存、RAID 等,对照机型手册)。

### 华为 FusionServer(通用语义,以 iBMC/手册为准)

- 绿色 = 正常;黄色闪烁 = 定位/重建;红色 = 故障;熄灭 = 无盘/离线
- 前面板告警灯 + iBMC 管理界面(`ipmcset` / Web)为最终依据

### 联想 ThinkSystem(通用语义)

- 绿色 = 正常/活动;琥珀色 = 警告/预测故障;琥珀红/红 = 故障
- XClarity Controller(XCC)Web 界面看详细事件

> 💡 **各家颜色语义大同小异,但闪烁频率和代际差异存在**,型号不同以官方《用户手册》灯码章节为准。上面三张表覆盖 90% 现场场景。

## 确认流程(灯码 → 软件交叉验证)

```bash
# 1. 灯码记录盘位(如 Slot 3 琥珀常亮)→ 进系统用 OMSA 确认
omreport storage pdisk controller=0 | grep -iE "Slot 3|Status|State"

# 2. 或 perccli(更精确)
perccli /call/eall/sall show | grep -iE "Slot 3|State|Firmware state"

# 3. 阵列卡事件日志,定位根因
perccli /call show events

# 4. 远程环境(机房无人):iDRAC/OMSA Web 界面查存储状态
# 浏览器打开 https://<iDRAC-IP> → Storage 页
```

关键状态词对照:`Online`=正常,`Rebuild`=重建,`Failed`=故障,`Offline`=掉线,`Foreign`=外部配置(盘来自其他阵列)。

## 验证方法

- 软件状态与灯码一致(如灯码琥珀常亮 ↔ perccli 显示 `Failed`)→ 判断成立
- 灯码琥珀闪烁 + 软件显示 `Rebuild` → 正在重建,**不要干预**
- 灯码正常但软件报错 → 以软件为准,查日志

## 注意事项 / 踩坑记录

- ⚠️ **禁止凭灯码直接拔盘**:琥珀灯 ≠ 一定该换,可能只是 PFA 预警或重建闪烁;先软件确认盘位+序列号
- **琥珀闪烁两义性**:重建闪烁 vs PFA 闪烁易混淆——重建时软件同步显示 `Rebuild %`,以此区分
- **热备盘灯态**:热备盘(未启用)可能是"熄灭/常绿"而非故障,别误判为掉线
- **LED 颜色受环境光影响**(红/橙难分),夜间巡检用手机照灯辅助,或直接看 iDRAC
- **老机型单灯设计**:活动/状态合一,颜色含义与双灯不同,先确认机型
- 灯码正常但阵列卡持续蜂鸣 → 查电源/风扇/BBU(电容)状态,不一定是硬盘问题
- 新盘插入后灯快速闪烁是"识别/重建"正常过程,不是故障
