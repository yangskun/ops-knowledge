    Windows 更新:禁用与恢复¶

    结论先行¶

    禁更分两步:组策略(专业版+)或注册表(家庭版)关闭自动更新 + 加固阻止手动更新,再清理残留更新文件。恢复时把策略改回"未配置"即可。⚠️ 长期禁更累积安全风险,建议每月临时恢复打补丁后重新禁用。

    现象¶

    • Windows 在无感知时自动下载/安装更新,导致驱动冲突、蓝屏、强制重启
    • 设置界面"检查更新"无法阻止,想彻底禁用自动与手动更新

    原因推测¶

    • Windows Update 服务(wuauserv)由系统自动触发,默认策略允许自动下载安装
    • 组策略"配置自动更新"控制自动行为;"删除使用所有 Windows 更新功能的访问权限"控制设置界面的手动入口(需启用才生效,见踩坑记录)
    • 更新残留文件堆积在 C:\Windows\SoftwareDistribution 与 C:\Windows\Temp,占用 C 盘空间

    分步操作¶

    第 1 步:关闭自动更新(按系统版本选择)¶

    专业版/企业版(组策略,推荐)

    1. Win+R → gpedit.msc → 计算机配置 → 管理模板 → Windows 组件 → Windows 更新
    2. 双击 配置自动更新 → 设为 "已禁用"(阻止自动更新)
    3. 加固:同一列表中找到 删除使用所有 Windows 更新功能的访问权限 → 设为 "已启用"(⚠️ 注意是"已启用",不是"已禁用"——启用后才移除更新功能访问权限,阻止通过设置界面手动触发更新)
    4. 执行 gpupdate /force 立即生效(管理员 CMD)

    家庭版(注册表,无组策略)

    1. Win+R → regedit → 定位至 HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU
    2. 新建 DWORD 值 NoAutoUpdate → 数值设为 1
    3. 重启或执行 gpupdate /force 生效

    💡 家庭版无组策略界面,加固项("删除使用所有...")仅适用于专业版及以上版本。

    第 2 步:清理残留更新文件(按优先级)¶

    1. DISM 深度清理(核心,⚠️ 不可逆)

    :: 管理员 CMD;清理后旧更新组件无法再卸载,确认后再执行
dism /Online /Cleanup-Image /StartComponentCleanup /ResetBase

    2. 手动清缓存

    :: 管理员 CMD;先停服务,清完再启动
net stop wuauserv
net stop bits
del /f /s /q C:\Windows\SoftwareDistribution\Download\*.*
del /f /s /q C:\Windows\Temp\*.*
net start bits
net start wuauserv

    3. 磁盘工具复核

    :: cleanmgr 勾选"Windows 更新清理"和"传递优化文件"
cleanmgr /d C:

    第 3 步:恢复更新(需要时)¶

    • 组策略:将上述两项策略改回 "未配置"(注意:"删除使用所有..."改回未配置 = 恢复访问权限)
    • 注册表:NoAutoUpdate 改为 0 或删除该项
    • 重启后恢复自动更新;如需立即检查,Win+R → wuauclt /detectnow(Win10 22H2+ 可用 usoclient StartScan)

    验证方法¶

    1. 打开"设置 → Windows 更新",页面提示 "某些设置由你的组织来管理",且"检查更新"按钮灰色不可点 = 禁用及加固均成功
    2. gpresult /r 可确认组策略应用状态(管理员 CMD)
    3. 清理后查看 C 盘可用空间变化

    注意事项 / 踩坑记录¶

    • ⚠️ 常见误区:原文/网上教程常把"删除使用所有 Windows 更新功能的访问权限"写成"设为已禁用"。该策略启用 = 删除访问权限(阻止手动更新),禁用/未配置 = 允许访问。设反了会导致加固无效
    • 安全平衡:长期禁更会累积漏洞风险,建议每月手动临时恢复安装关键补丁后重新禁用
    • 操作保险:全部操作完成后创建系统还原点(Win+R → rstrui 或 系统属性 → 系统保护 → 创建),异常可快速回滚
    • DISM ResetBase 不可逆:执行后无法卸载旧更新、无法回滚更新组件,生产环境先评估
    • 家庭版若想用组策略,可用 Windows 10 LTSC 或通过安装"组策略编辑器"工具包(仅个人设备)
    • 个别电脑禁用后"设置 → Windows 更新"仍显示可用更新列表,以"检查更新"按钮灰色为准
